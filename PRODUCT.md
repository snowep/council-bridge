# Council Bridge Product

## Overview
A governance platform for AI-powered organizations with divisions, staff agents, tasks, and automated executions.

## Core Workflows
1. **Organization Setup**: Create divisions, invite/manage staff
2. **Task Management**: Create, assign, and track tasks across divisions
3. **Deliverables**: Submit, review, and approve work products
4. **Executions**: Request and approve AI operations
5. **Council Governance**: Multi-agent decision making and voting
6. **Memory**: Semantic memory storage and retrieval for context

## Target Users
- Founders (system owners with full permissions)
- Division Heads (division-level management)
- Staff Agents (task execution and approvals)

## Platform
- Web application (React + MUI)
- Responsive design for desktop/tablet/mobile
- Dark/light theme support
