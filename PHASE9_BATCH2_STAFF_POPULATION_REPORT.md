## Issues Encountered

### Division ID Alignment (Resolved)
**Issue:** Initial script used display names as division_ids (e.g., "Developer Division") but existing database used lowercase IDs (e.g., "developer").

**Resolution:** Updated script to use correct division_ids matching existing schema:
- developer (not "Developer Division")
- marketing (not "Marketing Division")
- finance (not "Finance Division")
- creative (not "Creative Division")
- research-intelligence (not "Research & Intelligence Division")
- business-operations (not "Business Operations Division")

### FK Constraint on runtime_personas (Handled)
**Issue:** Foreign key from runtime_personas.persona_id → staff_agents.staff_id caused insertion failures during batch activation.

**Resolution:** Temporary `PRAGMA foreign_keys = OFF` during bulk runtime persona insertion, re-enabled after.
