---\n\n# MUI Standardization Skill for Council Bridge\n\n## When to Run\nRun when converting custom MUI component overrides to standard MUI v9 patterns. Applies to AppBar, Drawer, and navigation components in `frontend/src/app/layouts/Layout.tsx`.\n\n## Prerequisites\n- MUI v9.5.0 installed (`@mui/material`, `@emotion/react`, `@emotion/styled`)\n- Project using `ThemeProvider` wrapping the app\n- Layout component at `frontend/src/app/layouts/Layout.tsx`\n\n## Workflow\n### Step 1 - Identify Custom Overrides\nSearch for `sx` prop patterns that override MUI defaults:\n```bash\ngrep -rn 'sx=' frontend/src --include='*.tsx' | grep -v 'theme\\|palette\\|primary\\|secondary\\|background\\|text'\n```\n\n### Step 2 - Remove Custom sx Props\nReplace custom `sx` overrides with MUI standard:\n- **AppBar**: Remove `width`, `ml`, `backgroundColor`, `borderBottom`, `borderColor`, `boxShadow` from `sx`. Use `zIndex` only if stacking context needed.\n- **Drawer Permanent**: Remove `borderRight`, `borderColor: 'divider'` from paper `sx`. Add `border: 'none'` and `zIndex: 64` (one below AppBar z-index 65).\n- **Drawer Temporary**: Add `border: 'none'` and `zIndex: 64` to paper `sx` if missing.\n- **Drawer Menu Items**: Replace custom `StyledNavLink` with MUI standard `ListItem` + `ListItemButton` + `ListItemIcon` + `ListItemText`. Remove `borderRadius`, manual hover/active styles - use MUI built-in states.\n- **User Menu Box**: Ensure `borderBottom` uses string format `"1px"` not number `1`.\n\n### Step 3 - Verify Z-Index Stacking\nConfirm proper stacking: `AppBar z-index: 65` > `Drawer paper z-index: 64` > `main content`. Prevents overflow through AppBar.\n\n### Step 4 - TypeScript Compilation\nRun `npm run typecheck` - must pass with zero errors.\n\n### Step 5 - Lint Verification\nRun `npm run lint` - must pass with no new errors introduced.\n\n## Pitfalls\n- **Pitfall: z-index stacking conflict** - Without explicit z-index values (AppBar 65, Drawer 64), drawers overflow through the fixed AppBar. Always set both z-index values.\n- **Pitfall: borderRight on Drawer paper** - The permanent drawer historically had `borderRight: 1, borderColor: 'divider'` on the paper. This creates a visual divider that conflicts with the "clipped under appbar" behavior. Remove and use `border: 'none'` instead.\n- **Pitfall: StyledNavLink custom component** - Custom styled components with border-radius, margin, and hover states duplicate MUI's built-in `ListItem` interaction styles. Replace with `ListItemButton` + `ListItemIcon` + `ListItemText` for standard behavior.\n- **Pitfall: description arrows (->)** - When writing skill descriptions, avoid `->` arrows in the YAML description field as they may cause parse errors. Use plain language instead.\n- **Pitfall: sx prop over-engineering** - MUI's theming system (`palette`, `typography`, `shape`) should handle most styling. Only add `sx` overrides when the design requires deviation from MUI defaults.\n\n## MUI Standard Patterns\n### AppBar Standard\n```tsx\n<AppBar position=\"fixed\" elevation={0} sx={{ zIndex: 65 }}>\\n  <Toolbar>...\\n</Toolbar>\\n</AppBar>\n```\n\n### Permanent Drawer Standard\n```tsx\n<Drawer variant=\"permanent\" sx={{\\n  display: { xs: 'none', md: 'block' },\\n  width: drawerWidth,\\n  flexShrink: 0,\\n  '& .MuiDrawer-paper': {\\n    boxSizing: 'border-box',\\n    border: 'none',\\n    backgroundColor: 'background.paper',\\n    zIndex: 64,\\n  }\\n}}\\n  open\\n>\\n  {drawer}\\n</Drawer>\n```\n\n### Temporary Drawer Standard\n```tsx\n<Drawer variant=\"temporary\" open={mobileOpen} onClose={handleDrawerClose} ModalProps={{ keepMounted: true }} sx={{\\n  display: { xs: 'block', md: 'none' },\\n  '& .MuiDrawer-paper': {\\n    boxSizing: 'border-box',\\n    border: 'none',\\n    backgroundColor: 'background.paper',\\n    zIndex: 64,\\n  }\\n}}\\n>\\n  {drawer}\\n</Drawer>\n```\n\n### ListItem Navigation Standard\n```tsx\n<ListItem key={item.path} disablePadding>\\n  <ListItemButton component=\"a\" sx={{ textDecoration: 'none' }} to={item.path} end>\\n    <ListItemIcon>{item.icon}</ListItemIcon>\\n    <ListItemText primary={item.label} />\\n  </ListItemButton>\\n</ListItem>\n```\n\n## Commands\n- `npm run typecheck` -
