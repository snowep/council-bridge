# Karpathy Guidelines Skill

**Purpose:**
Reduce common LLM coding mistakes by following behavioral guidelines derived from Andrej Karpathy's observations.

**Key Principles:**
1. **Think Before Coding:**
   - Define clear success criteria before writing code.
   - Ask: "What is the smallest change that fully solves the task?"

2. **Keep It Simple:**
   - Avoid over-engineering. Use existing patterns and libraries.
   - Prefer one-liners and minimal changes.

3. **Make Surgical Changes:**
   - Edit only what is necessary. Avoid unnecessary abstractions.
   - Ensure changes do not break existing functionality.

4. **Define Success Criteria:**
   - Clearly state what success looks like before starting.
   - Verify changes meet the criteria.

**Usage:**
- Use this skill before starting any coding task.
- Follow the principles to avoid common pitfalls.

**Example:**
- If you are tasked with adding a feature, ask:
  - What is the smallest change that achieves the goal?
  - Does this change break anything else?
  - How can I verify the change works?
